## 2. 段落与换行
普通文字直接写就是段落。

软换行（行末尾两个英文空格，再回车）  
软换行，和上一行属于同一段落。

强制换行（兼容性最好）<br>
这是br标签换行。

空一行，代表开启全新段落。
